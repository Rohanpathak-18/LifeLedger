# LifeLedger project scope

LifeLedger keeps product records, purchase documents, warranties, repairs, maintenance, and ownership costs together. The interface follows the supplied reference: warm ivory surfaces, deep charcoal navigation, restrained brass accents, editorial serif headings, and responsive product imagery.

## Delivery phases

- **Phase 1 (current):** Monorepo foundation, responsive UI shell, environment validation, MongoDB connection, API health, account registration/login, access tokens, and rotating refresh sessions.
- **Phase 2:** Persisted product inventory, dashboard metrics, search/filter/pagination, and warranty tracking.
- **Phase 3:** Private documents, reviewable receipt extraction, repairs, maintenance, and reminders.
- **Phase 4:** Grounded assistant and document retrieval.
- **Phase 5:** Broader test coverage, security review, deployment, and operational hardening.

Future phases must keep each resource owner-scoped and must not treat AI-extracted data as trusted until a user confirms it.
